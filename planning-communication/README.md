# Planning and Communication

- **Technology Board Reporting Framework** - a structure and cadence for reporting technology, security, and delivery posture to a board of directors: risk posture, named top risks, compliance status, investment versus plan, and what's coming next, built around a one-page summary and a defined out-of-cycle escalation path so the quarterly report never contains a surprise.
- **Target-State Narrative Template** - a prose-first structure for describing a future operating model to executive audiences, built around the idea that diagrams illustrate but should never replace clear writing.
- **Capability-Driven Roadmap Method** - a method for building multi-year roadmaps rooted in capability gaps rather than technology initiatives, with traceability from strategy to initiative.
- **Business Case Template and Narrative** (workbook + companion document) - a financial model paired with the narrative structure that makes it defensible to executives and finance reviewers alike, including an honest options analysis and named benefit owners.
- **Architecture Decision Record (ADR) Template** - a durable format for capturing significant, hard-to-reverse decisions along with the context and alternatives considered, plus the conventions that keep an ADR practice alive rather than decorative.

*Full working templates and facilitation guides are available through direct engagement. See the repository root README for the complete catalog and license terms.*
