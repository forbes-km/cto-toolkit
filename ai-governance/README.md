# AI Governance

- **AI Governance Playbook** - a practical framework for governing AI and LLM deployment in regulated environments: risk tiering, use case intake and approval, data governance for AI, model and vendor risk, human oversight and accountability, and monitoring and incident response, built around a one-page canvas for capturing and auditing any single use case decision.

*Full working version of this playbook, including the risk-tiering worksheet and intake templates, is available through direct engagement. See the repository root README for the complete catalog and license terms.*
