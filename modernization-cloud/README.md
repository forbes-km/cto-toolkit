# Modernization and Cloud Transformation

- **Cloud Migration Playbook** - program structure for cloud migrations from landing zone readiness through discovery, disposition, wave execution, cutover, and decommission.
- **Modernization Decision Playbook** - a scoring model for making application disposition decisions across a portfolio, paired with a stakeholder interview guide, so modernization choices are made at the portfolio level rather than drifting one application at a time.
- **Cloud Service Mapper** (usage guide + interactive tool) - an interactive reference tool, with underlying provider reference libraries for AWS, Azure, GCP, and OCI plus a multi-cloud equivalence view, for translating services and capabilities across providers. A working version of this tool is open source: see `/tools/cloud-service-mapper`.
- **Integration Patterns Catalog** - a selection guide and pattern library covering synchronous, asynchronous, and data integration patterns, plus common combinations, for choosing integration approaches deliberately rather than by habit.
- **Cloud Cost Optimization & FinOps Playbook** - a four-phase method (visibility, rightsizing and elimination, commitment and pricing optimization, architectural efficiency) for reducing and governing cloud spend as an ongoing discipline rather than a periodic cleanup, with team-level cost ownership built in so savings don't quietly revert.

*Full working versions of the playbooks above are available through direct engagement. See the repository root README for the complete catalog and license terms.*
