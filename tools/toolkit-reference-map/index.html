Toolkit Reference Map

Most pages in this toolkit follow the same shape: a concept, grounded in a framework, tested against a diagnostic, pointed at a decision. Where they differ, and where it matters for how you use them, is what you walk away with. Some pages end in an interactive tool you run yourself. Some end in a decision checklist, structured judgment, not a calculator. A few are conceptual grounding with no built-in tool at all. This page groups all 61 by which one, checked against each page's real content rather than assumed uniform.

"Preview" tags mark pages that cover the thinking behind a larger toolkit, templates, question banks, or facilitation guides, that's available through direct engagement rather than delivered on the page itself. Everything else on this page is complete as published.
