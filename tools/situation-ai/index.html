We're Introducing AI

The pressure is probably coming from the board or the CEO, the use cases are probably vague, and there are probably already three unsanctioned tools in use. The job is not to slow this down; it is to give it a structure so that the money goes to initiatives that can actually ship, the data is ready when they do, and the governance exists before the first regulator or customer asks about it. This page sequences the decisions and links to the pages that hold the detail.

Questions to ask

Questions that separate initiatives from demos

Ask these of every proposed initiative before it gets a budget line, and again before it goes to production.

  • For each proposed initiative, what data does it need, does it exist, who owns it, and what is its quality today
  • Which initiatives would be valuable if they worked, and which are being proposed because they are visible
  • What is the organization's actual tolerance for a wrong answer in this use case, and who has said so
  • Which of the current AI tools in use retain or train on the data sent to them, and what has been sent
  • Where does a human review the output, and is that review real or a checkbox
  • What does the first initiative cost per transaction at production volume, not at demo volume
  • Which regulations already apply to the decisions the AI will influence, regardless of the fact that it is AI
  • If the model provider changed pricing, terms, or availability tomorrow, what would break and how fast could it be swapped
  • What would the organization stop doing if this initiative succeeded, and does anyone want to stop doing it
The trap

Pilot sprawl

The most common state of an enterprise AI program at month nine is a dozen pilots, each with a champion, none with a kill criterion, and no way to say which of them the company is actually betting on.

What it looks like

Every function got a pilot approved because saying no felt like being against AI. Each one used a different provider, built its own prompt library, and stored its own copy of the data. Six are technically working, none are in production, the cost is now visible on the cloud bill, and the board asks what the company got for it. The honest answer is a set of demos.

The counter-move

Run it as a portfolio from day one, with the gating in AI Portfolio Management: feasibility and data readiness before anything else, an explicit Kill classification that is used, and a cap on concurrent incubations. Pay for the platform layer once, centrally: guardrails, observability, retrieval, and cost attribution. Measure unit economics on the first production initiative before scaling anything, and report the portfolio to the board as a portfolio, including the kills.

Outputs

What should exist at 30, 90, and 180 days

A program that can show these artifacts is a program the board can fund with confidence. One that cannot is a set of pilots.
