# Samples

Redacted or fully synthetic example outputs, included so the tools in this repository can be evaluated by what they produce, not just by their description.

- `sample_100_day_plan.md` - a synthetic 100-day remediation plan as produced by the Diligence Prioritization Engine (see `/technology-diligence`), generated from fictional deal data.

More samples will be added over time as tools produce redacted output safe to share.
